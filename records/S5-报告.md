## 二、实验设置（标定后）

| 项 | 值 |
|---|---|
| 搜索空间 | `max_num_seqs∈[16,256](log)` × `max_num_batched_tokens∈[16,8192](log)` × `watermark∈[0.001,0.2](log)`；`block_size=16` 固定（Vidur profiling 限制） |
| 负载 | qps=12.0、384 请求、splitwise_conv trace（容量 ≈9.4 rps，排队区） |
| SLO | TTFT p90 ≤ 1.0s、TPOT p90 ≤ 0.1s（标定后收紧，目标强判别：跨配置 goodput 0.79–8.96） |
| 成本模型 | 合法试验 = 1 单位；非法/失败 = 1 + c_invalid（c_invalid = 3） |
| 采样器 | Optuna TPE，每 study 独立种子（20 种子/臂） |
| 约束映射 | M = SCOOT 式人工约束的 Vidur 投影（mtib ≥ max(mns, 1024)，即"#1 mtib≥mns + #3 无 chunked prefill 时 mtib≥最大序列"）；A = 约束图投影（本子空间下与 M 等价，见 §四） |

## 三、为什么 N 臂会付出 48.6% 的额外成本

- N 臂在 `[16,8192]` 上**对数均匀**采样 `mtib`：其中 `mtib < 1024`（负载最大 prefill 之下）的区间占**对数尺度约 2/3** 的抽样概率；
- 但 TPE 会随试验学习避开高失败区：**实际违规率收敛到 31.5% ± 5.1%**（不是理论上的 67%）；
- 每次违规按 `1 + c_invalid = 4` 单位计费：`30 + 9.45 × 3 = 58.35` 单位 —— **与实测 58.350 ± 4.614 完全吻合**（口径交叉验证）；
- 对照：M/A 臂把约束作为采样下界，非法率 = 0，成本恰为 30 单位。

> ⚠️ **方法学细节（写进论文）**：约束的"空间缩减率"（离散计数）只有 **12.3%**，但在**对数采样**下它移除了约 2/3 的抽样概率、实际计费违规率 31.5%。**约束的价值取决于采样分布**——只看空间体积会低估其收益。两个口径都要报。

## 四、诚实声明：M 与 A 在本子空间退化

- Vidur 的 vLLM(V0) 参数子空间只有 3 个有效采样维度，M（SCOOT 投影）与 A（约束图投影）在此子空间**恰好等价**（同一条 mtib 下界）；
- **因此 S5 证明的是"有约束 vs 无约束"的价值（G2），而不是"自动 vs 人工"的优劣**；
- "自动 vs 人工"的差异由 **S4 在真实引擎上**回答：人工清单 3 条（且 1 条已失效） vs 自动抽取 113 条 confirmed；以及 S6 的跨引擎结果。
- 这是设计时就预判的退化（见 `S5-实验设计-v1.md` §七-3），报告中如实标注。
